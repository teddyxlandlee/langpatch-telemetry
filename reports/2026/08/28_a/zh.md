## 1. 遥测参与度与数据质量

### 总量概览
- **遥测数据总行数:** 489,896  
  在这16天内，模组共上报了 **489,896** 条有效遥测记录。

  **重要解读说明：** 与上一周期（12天共216,863条，日均约18,072条）相比，本周期日均数据量（约30,619条）**显著增加约69%** 。这一增长主要归因于 schema v3 遥测数据的成功记录（见下文），以及持续的版本升级可能导致的会话计数器重置，也可能反映了用户参与度的提高。

- **Schema 版本分布:**
  - `schema_version 2`: **399,223** (81.5%)
  - `schema_version 3`: **90,673** (18.5%)

  > **关于 Schema v3 的重要说明：** 版本 **3.8.15** 引入了新的遥测 schema（`schema_version 3`），新增了“注册的补丁数量”这一收集项。上一报告中提到的中间件问题已解决，因此本周期首次包含了 schema v3 数据，使我们能够分析模组集成情况（见第6节）。

- **遥测级别:** 所有记录均为 `"lvl1"`（Functional 级别）。

## 6. 补丁数量分析（Schema v3）

Schema v3 引入了新指标：`patch_count`。模组自身注册了2个补丁（附魔和药水）。补丁数量为3或以上表示有其他模组通过API与 Enchantment Level Language Patch 进行了集成。

- **Schema v3 总记录数:** 90,673
- **补丁数量分布:**
  - `patch_count = 2`: **90,535** (99.8%)
  - `patch_count = 3`: **138** (0.2%)

**关键发现:**
- 绝大多数 schema v3 客户端（99.8%）使用默认的2个补丁，表明大多数用户独立运行该模组。
- **138条记录（0.2%）显示3个或以上补丁**，确认至少有一些其他模组正在积极与 Enchantment Level Language Patch 集成。这是模组生态可扩展性的积极信号。

## 8. 服务器状态

遥测后端（腾讯云香港地区）持续稳定运行。如之前公告，服务器**不再接收来自 3.8.5 及以下版本的遥测数据**。建议用户使用 **v3.8.13 或更高版本** 以继续支持遥测分析。

> 关于数据存储于中国香港特别行政区的最新条款，请参阅 [隐私政策页面](https://privacy.ellp.mods.hixland.com/privacy)。

## 9. 总结与展望

在本次遥测周期（2026年8月12日至8月28日）中，Enchantment Level Language Patch 的用户基础发生了显著变化：

- **数据量**：16天内总记录达 **489,896** 条。日均数据量较上期增加约69%，表明数据收集改进以及用户参与度可能提高。

- **版本多样性**：**3.8.11** 成为主导版本（52.8%），而 **3.8.18** 增长至11.9%。**3.8.13** 降至18.5%。分布显示用户明显向3.8.11和最新版3.8.18迁移。

- **游戏版本迁移**：**1.20.1** 大幅上升至65.0%，而 **1.21.1** 降至24.2%。新方案版本（26.x）现占约6.2%，显示稳定 adoption。

- **平台格局**：**Forge** 重新占据主导地位（65.5%），而 **Fabric** 降至27.0%。**NeoForge** 降至7.5%。

- **地域集中度**：**中国大陆** 上升至71.7%，表明用户集中度提高。

- **生态健康度**：schema v3 和补丁数量指标的引入显示，**0.2%的 schema v3 用户存在模组集成**，表明生态系统的可扩展性良好。

- **未来展望**：随着 schema v3 数据的成功记录，未来报告将提供更深入的模组集成分析。建议用户保持模组更新至最新版本，以享受改进并支持遥测。
