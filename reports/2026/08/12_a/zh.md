## 6. 补丁数量分析（Schema v3）

Schema v3 引入了新指标：`patch_count`。模组自身注册了2个补丁（附魔和药水）。补丁数量为3或以上表示有其他模组通过API与 Enchantment Level Language Patch 进行了集成。

- **Schema v3 总记录数:** 47,622
- **补丁数量分布:**
  - `patch_count = 2`: **47,201** (99.1%)
  - `patch_count = 3`: **421** (0.9%)

**关键发现:**
- 绝大多数 schema v3 客户端（99.1%）使用默认的2个补丁，表明大多数用户独立运行该模组。
- **421条记录（0.9%）显示3个或以上补丁**，确认至少有一些其他模组正在积极与 Enchantment Level Language Patch 集成。这是模组生态可扩展性的积极信号。

## 9. 总结与展望

在本次遥测周期（2026年7月31日至8月12日）中，Enchantment Level Language Patch 展现了持续的生态演进：

- **数据量**：12天内总记录达 **216,863** 条。日均数据量较上期增加约27%，表明数据收集改进以及用户参与度可能提高。

- **版本多样性**：**3.8.13** 仍是最常用版本（35.4%），但新版本如 **3.8.17**（10.1%）和 **3.8.18**（0.9%）正在获得关注。**3.8.15** 现占9.1%，得益于 schema v3 修复。

- **游戏版本迁移**：**1.21.1**（41.8%）仍是领先游戏版本，紧随其后的是 **1.20.1**（40.5%）。新方案版本（26.x）现占约10.1%，显示稳定 adoption。

- **平台格局**：**Fabric**（44.7%）保持对 **Forge**（41.3%）的领先，而 **NeoForge** 增长至13.9%，为历史最高。

- **地域多元化**：**中国大陆**仍以51.2%领先，但占比下降，反映用户群体更加全球化。

- **生态健康度**：schema v3 和补丁数量指标的引入显示，**0.9%的 schema v3 用户存在模组集成**，表明生态系统的可扩展性良好。

- **未来展望**：随着 schema v3 数据的成功记录，未来报告将提供更深入的模组集成分析。建议用户保持模组更新至最新版本，以享受改进并支持遥测。
