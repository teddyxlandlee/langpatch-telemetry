###  EnchLevel-LangPatch 月度遥测快照 (2026-04 数据回顾)

**发布日期：** 2026年5月7日  
**统计周期：** 2026年4月5日 - 2026年5月6日  
**总样本量：** 84,526 次回传

大家好，我是 EnchLevel-LangPatch 的开发者。秉承隐私政策中的透明承诺，我整理了上个月的匿名遥测数据。这份报告不包含任何个人身份信息（IP/UUID），仅用于分析模组的运行环境和生态分布。

#### 1. 遥测参与度与数据质量
首先，关于数据的来源：
*   **隐私偏好：** 数据显示所有样本均为 `telemetry_level: lvl1`。这意味着**没有任何用户主动开启“详细模式”**。这符合预期，毕竟大多数用户倾向于保持默认设置或为了隐私彻底关闭遥测。
*   **版本一致性：** 在 `mod_version` 维度上，绝大多数用户集中在最新版本（3.8.5），这符合预期，说明玩家普遍保持模组更新。
*   **Schema 分布：** 数据结构版本（Schema）的比例约为 **13:71**，进一步佐证了绝大多数用户使用的是兼容最新规范的客户端。

#### 2. 核心运行环境分析 (Platform & Minecraft)
这是本次分析的重点。我们来看 `platform_mcv`（平台+游戏版本）的分布情况。

**主流生态（占据了 80% 以上的份额）：**
*   **Fabric + 1.21.11:** 这是目前最庞大的用户群体。Fabric 依然是高版本 Modding 的首选，且用户升级非常迅速。
*   **NeoForge + 1.21.1:** 随着 NeoForge 的成熟，它在 1.21.1 这个稳定版本上拥有大量的拥趸。
*   **Forge + 1.20.1:** 这是“稳如泰山”的老将。在 1.20.x 时代，Forge 依然保持着强大的生命力，拥有极其稳定的用户基数。

**前沿与特殊环境（虽然人少，但很有趣）：**
遥测数据也捕捉到了一些非常规的环境，这证明了模组的兼容性覆盖很广：
*   **Minecraft 26.x 系列：** 这是一个值得关注的亮点。数据显示有相当一部分用户（约 7,454 人）已经升级到了 **26.1.2** 正式版，甚至还有部分极客玩家正在测试 **26.2-snapshot** 快照版本。这说明核心玩家群体对新技术的尝鲜意愿非常强烈。
*   **远古版本：** 依然有用户在使用 `1.12.2` 和 `1.16.5`。虽然 EnchLevel-LangPatch 主要面向新版本，但能兼容这些老环境实属意外之喜。
*   **冷门平台：** Quilt 虽然份额极小（仅 229 次回传），但确实存在，证明了跨平台兼容层的有效性。

#### 3. 功能使用现状：LangPatch API
关于扩展性功能的数据令人深思：
*   **Hooks 数据为空：** 在 `current_hooks` 和 `all_hooks` 维度中，`enchantment` 和 `potion` 的数据均为 `{}` 空值。
*   **分析结论：** 这说明目前 LangPatch 的 Java API 及第三方扩展机制**并未被广泛使用**。
*   **开发者自省：** 我个人认为，这很大程度上是因为我没有做好 API 的宣传和文档推广。目前大家主要还是将 EnchLevel-LangPatch 作为一个“开箱即用”的翻译模组，而没有挖掘其作为“翻译开发库”的潜力。这将是未来需要改进的方向。

#### 4. 地域与时间分布
*   **主要分布：** 数据呈现出明显的区域性特征。
    *   **中国 (China / Shanghai):** 毫无疑问是核心区域，占据了最大份额。这也符合我（开发者）所在的社区环境。
    *   **北美与欧洲：** 美国、德国、英国和俄罗斯的用户构成了第二梯队，分布较为均匀。
*   **多样性：** 虽然核心在东亚和北美，但数据中也包含了来自东南亚（泰国、越南）、南美（巴西）以及中东地区的回传，体现了 Minecraft 社区的全球多样性。

#### 5. 待排查问题
*   **空版本号 (Empty MC Version):** 数据中存在 `3,203` 次空字符串 (`""`) 的 `mc_version` 记录。
*   **现状：** 目前原因未知。这可能是由特定的启动器环境、极老的模组加载器冲突，或者是极罕见的运行时异常导致的捕获失败。这需要在后续版本中加入更详细的诊断逻辑来定位。
